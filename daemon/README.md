# The launchd agents

```bash
daemon/install.sh              # the brain: runs at login, restarts if it dies
daemon/install.sh --telegram   # and the Telegram bot
daemon/uninstall.sh            # remove both
```

Per-user agents, so no `sudo`. `install.sh` refuses if credentials are missing rather
than installing something that will crash-loop, and stops a hand-started brain first
so the two do not fight over port 7777.

- `com.arup.jervis` - the brain on localhost:7777. This is the one that matters.
- `com.arup.jervis.telegram` - the bot. Optional, and installed only with `--telegram`.

The voice loop is deliberately not installed as an agent: it holds the microphone open,
and it is parked as choppy (PLAN.md §4c). Run it by hand with `scripts/start.sh --voice`.

```bash
uv run jervis status     # is the agent running, and what can it reach
scripts/logs.sh          # tail the brain
scripts/logs.sh audit    # every tool call, as it happens
scripts/stop.sh          # stop now, but it still starts again at login
```

The plists are generated by `jervis_brain.daemon`, not hand-edited. Editing
`~/Library/LaunchAgents/com.arup.jervis.plist` directly works until the next
`install.sh`, which overwrites it - change the generator instead.
